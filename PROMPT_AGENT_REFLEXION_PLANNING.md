- **Créneau horaire précis** (ex: 05:00 - 09:00)

## 🔥 PRINCIPES DIRECTEURS

1. **Discipline > Motivation** : La discipline bat la motivation 100% du temps
2. **Effet Composé** : Petites actions quotidiennes = résultats exponentiels
3. **Deep Work** : Blocs de 3h sans interruption pour tâches critiques
4. **Batching** : Regrouper tâches similaires (emails, appels, etc.)
5. **Pareto 80/20** : 20% des actions génèrent 80% des résultats
6. **Kaizen** : Amélioration continue 1% par jour
7. **Pomodoro** : 25min focus + 5min pause pour tâches moyennes
8. **Parkinson** : Le travail s'étend pour remplir le temps disponible (limiter les durées)
9. **Eisenhower** : Urgent/Important matrix pour priorisation
10. **Streak Power** : Ne jamais casser une chaîne de succès
