# Design Brief: Dashboard Personnelle

## Problem Statement
The current dashboard lacks a refined, aesthetically pleasing interface that reflects the discipline required for a "Commander VIP." Data exists, but it is not organized to highlight the interdependence between daily discipline (Sport, Reading, Cleaning) and the primary pillars: Spirituality and the SaaS project.

## Users
Commander VIP. Needs a clean, high-performance, inspiring interface to pilot this daily interconnection.

## Design Direction
A holistic interface:
- **Primary Pillars (Spirituality & SaaS)** are the high-level KPIs.
- **Daily Discipline (Socle)** is presented as the essential engine/foundation fueling the primary pillars.
- **Aesthetic**: Sobriety, clarity, and strong visual hierarchy. Every element must be intentional to avoid cognitive overload.

## Constraints
- Must remain functional for daily data entry.
- Tech stack: React + Vite + TypeScript.

## Existing Design System
None (will be defined).

## Taste Direction (Early Signal)
- Seeking a premium, focused aesthetic. 
- Needs to feel "alive," "polished," and consistent.

## Success Criteria
- Instant clarity on the correlation between daily discipline (base) and results on the pillars (Spiritual & SaaS).
- Increased daily engagement through a rewarding visual experience.

## Out of Scope
- Changing the underlying data structure (for now).
